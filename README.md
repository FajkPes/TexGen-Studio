# TexGen Studio

A browser-based procedural texture tool for creating patterns and materials without installation.

## Key features

- Combine procedural layers, masks and effects.
- Save projects and build a local gallery.
- Export images as PNG, JPEG or WebP.

## Get started

Download the ZIP from Releases and open `index.html` in a browser with WebGL.
